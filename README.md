# أولغا — ملفات الموقع بعد التقسيم (olga-split_v1)

نفس صفحة `Olga_v19_1.html` بالضبط: نفس الشكل والنصوص والأسعار والحركات، لكن الكود صار موزّعاً على ملفات منفصلة بنفس أسلوب مشروع فاست تكنو.

## شكل المجلد

```
olga-split_v1/
├── index.html                 ← هيكل الصفحة (HTML فقط)
├── style.css                  ← كل التنسيقات
├── script.js                  ← كل أكواد JavaScript (بنفس الترتيب الأصلي)
└── assets/
    ├── img/                   ← 38 صورة للموقع (webp)
    └── data/
        ├── config.js          ← عناوين السيرفرات والخدمات الخارجية
        ├── content.js         ← كل محتوى المتجر (المنتجات، الأسعار، النصوص…)
        ├── images.js          ← خريطة الصور: اسم الصورة ← الملف في assets/img
        ├── cutouts.js         ← صور العبوات المفرّغة + شعار أولغا
        ├── shams-img.js       ← صور شخصية المساعدة «شمس»
        ├── shams-poses.js     ← حركات يدي «شمس»
        ├── shams-voice-tour.js     ← تسجيلات صوت جولة «شمس» في الأقسام
        └── shams-voice-products.js ← تسجيلات صوت شرح المنتجات
```

## أين أعدّل؟

| أريد أن أغيّر… | الملف |
|---|---|
| سعر أو حجم أو وصف منتج | `assets/data/content.js` ← `products` |
| أي نص في الموقع (عربي/إنجليزي) | `assets/data/content.js` ← `texts` |
| رقم واتساب الطلبات | `assets/data/content.js` ← `whatsapp` |
| المدن وطرق الدفع | `assets/data/content.js` ← `cities` و `payments` |
| شرائح الواجهة الرئيسية | `assets/data/content.js` ← `heroSlides` |
| معلومات وإجابات «شمس» | `assets/data/content.js` ← `assistant` |
| صورة من صور الموقع | ضع الصورة في `assets/img` وغيّر اسمها في `assets/data/images.js` |
| عنوان سيرفر «شمس» أو إعدادات الخريطة | `assets/data/config.js` |
| الألوان والخطوط والتصميم | `style.css` |

## السيرفرات المرتبطة بالموقع

كلها مجمّعة في `assets/data/config.js`:

1. **سيرفر المساعدة «شمس»** (مشروع على Lovable Cloud):
   - `…/api/public/olga-chat` — ردود الذكاء الاصطناعي
   - `…/api/public/olga-tts` — صوت الردود
   - إذا لم يستجب السيرفر، تجيب «شمس» تلقائياً من معلومات المتجر في `content.js`.
2. **الخريطة في صفحة إتمام الطلب**: مكتبات MapLibre / Leaflet وخوادم البلاطات (OpenFreeMap و ArcGIS).
3. **البحث عن العناوين**: nominatim.openstreetmap.org.
4. **الطلبات**: تُرسل عبر واتساب إلى الرقم الموجود في `content.js`.
5. **مكتبات خارجية**: three.js و Google Fonts.

## لوحة التحكم

ملف `content.js` هو المكان الوحيد لمحتوى المتجر، ويُعرّف متغيراً واحداً `window.OLGA_CONTENT`.
لربط لوحة تحكم يكفي أن تُنتج اللوحة ملفاً بنفس الشكل وتستبدل به `content.js`، أو أن تملأ `window.OLGA_CONTENT` قبل تحميل `script.js` — بدون أي تعديل على باقي الكود.

## ملاحظات مهمة

- احتفظ بكل الملفات والمجلدات معاً كما هي؛ `index.html` يعتمد على المسارات النسبية.
- الموقع يعمل على أي استضافة، ويعمل أيضاً عند فتح `index.html` مباشرة من الجهاز.
- ترتيب ملفات `<script>` في آخر `index.html` مهم: ملفات البيانات أولاً ثم `script.js`.
- نصوص جولة «شمس» (`tourLines`) وشرح المنتجات (`productGuide`) لها تسجيلات صوتية جاهزة؛ تعديل النص لا يغيّر التسجيل.
- صور العبوات المفرّغة وصور «شمس» بقيت مضمّنة داخل ملفات JS لأن الموقع يقرأ بكسلاتها (العرض ثلاثي الأبعاد)، وهذا ضروري لكي يعمل الموقع حتى عند فتحه من الجهاز.
