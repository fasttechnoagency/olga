# أولغا — موقع المتجر (نسخة مقسّمة v1)

هذه هي نفس صفحة `Olga_v32.html` تماماً (نفس الشكل ونفس الحركة ونفس الربط مع السيرفرات)،
لكنها مقسّمة إلى ملفات منفصلة بدل ملف واحد حجمه 17 ميغابايت، بنفس أسلوب تقسيم مشروع فاست تكنو.

## هيكل الملفات

```
olga-split_v1/
├── index.html                  ← هيكل الصفحة فقط (الأقسام، الأزرار، النماذج)
├── style.css                   ← كل التنسيقات (11 قسماً بترتيبها الأصلي)
├── script.js                   ← كل الأكواد البرمجية (بترتيبها الأصلي، كل قسم معزول عن غيره)
└── assets/
    ├── data/
    │   ├── config.js               ← عناوين السيرفرات (لوحة التحكم + سيرفر شمس)
    │   ├── content.js              ← المنتجات، الأسعار، الأحجام، الأقسام، الريلز، وكل نصوص الموقع (عربي/إنجليزي)
    │   ├── media.js                ← قائمة الصور + صور المنتجات المفرّغة + الشعار
    │   ├── shams-knowledge.js      ← معلومات المساعدة «شمس» (المنتجات والأسعار والإجابات)
    │   ├── shams-poses.js          ← حركات جسم شمس
    │   ├── shams-images.js         ← صور جسم ووجه شمس
    │   ├── shams-voice.js          ← تسجيلات صوت شمس في جولة الموقع
    │   └── shams-voice-products.js ← تسجيلات صوت شمس عن كل منتج
    └── img/                    ← 38 صورة (البانرات وصور اللايف ستايل) كملفات webp حقيقية
```

## السيرفرات ولوحة التحكم

كل عناوين السيرفرات أصبحت في ملف واحد: `assets/data/config.js`

| الإعداد | الوظيفة |
|---|---|
| `OLGA_DB_URL` | قاعدة بيانات لوحة تحكم أولغا: الطلبات تُرسل إليها (`place_order`) ورسوم التوصيل تُقرأ منها (الإعدادات ← deliveryAmman / deliveryOther) |
| `OLGA_DB_KEY` | المفتاح **العام** (publishable) للقاعدة — آمن داخل الموقع. لا تضع أبداً مفتاحاً سرياً (service role) هنا |
| `OLGA_HALA_API` | سيرفر شمس: إجابات المحادثة (`olga-chat`) وصوتها المباشر (`olga-tts`) |

إذا تغيّر عنوان أي سيرفر، عدّله في `config.js` فقط ولا داعي للمس الكود.
إذا تعذّر الوصول للوحة التحكم، يبقى بإمكان الزبون إرسال الطلب نفسه عبر واتساب (كما في الأصل).

## التعديلات الشائعة

- **منتج أو سعر أو نص:** `assets/data/content.js`
  (الأسعار النهائية ورسوم التوصيل في الطلب تحددها لوحة التحكم).
- **ما تعرفه شمس عن المنتجات والأسعار:** `assets/data/shams-knowledge.js`
  — عند تغيير سعر في `content.js` غيّره هنا أيضاً حتى تجيب شمس بالسعر الصحيح.
- **صورة بانر أو صورة لايف ستايل:** استبدل الملف داخل `assets/img/` بنفس الاسم.
- **رقم واتساب:** `var WA=` في `script.js` (قسم olga-app) و `whatsapp` في `shams-knowledge.js`.
- انتبه للفواصل `,` والأقواس `[ ] { }` داخل ملفات البيانات؛ خطأ صغير فيها يوقف تحميل المتجر.

## ملاحظات تقنية

- ترتيب تحميل الملفات في نهاية `index.html` مهم: البيانات أولاً، ثم مكتبة three.js، ثم `script.js`.
- صور المنتجات المفرّغة (CUT) وصور شمس بقيت مضمّنة داخل ملفات البيانات لأن الصفحة تعيد رسمها
  (المصغّرات، العارض ثلاثي الأبعاد)، وهذا يسمح أن يعمل الموقع حتى عند فتح `index.html` مباشرة من الجهاز.
- مكتبات الخرائط (MapLibre / Leaflet) والخطوط تُحمّل من الإنترنت كما في الأصل.
- للرفع على الاستضافة: ارفع المجلد كاملاً كما هو (index.html في جذر الموقع).
