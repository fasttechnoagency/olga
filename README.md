# Olga v25 — split edition
Same site as Olga_v25.html, split into separate files. Nothing in the design or behavior was changed.

- index.html — page structure only
- style.css — all styles (original order, each block labeled)
- script.js — all site code (original order, each block labeled)
- config.js — server connections: control-panel database (orders, delivery fees) and the Shams/Olga assistant server. Change servers here only.
- assets/data/images.js — product and lifestyle photos
- assets/data/voice-tour.js, voice-products.js — recorded assistant voices
- assets/data/olh-knowledge.js, olh-poses.js, olh-img.js — assistant knowledge, poses and portrait

Upload the whole folder to a web host. The control panel and assistant work only from an approved web address.
